# v1.6.0 - Topology-aware CAD visual grounding

v1.6.0 makes visual findings substantially easier to connect back to exact
AutoCAD geometry. It adds drawing-level topology, real path/polygon grounding,
stronger snapshot contracts, and a calibrated review/evaluation loop while
preserving the existing handle-first safety model.

## Highlights

- **Drawing-level boundary topology** - assemble closed profiles across lines,
  arcs, splines, and entity boundaries instead of treating every entity as an
  isolated box.
- **Supported intersections and closed-loop traversal** - split boundary
  segments at line-line and supported line-curve intersections, traverse
  half-edge candidates, and fail closed for unsupported or ambiguous cases.
- **Path and polygon grounding** - return geometry-shaped regions, multi-handle
  candidates, ambiguity signals, and semantic shape evidence for VLM findings.
- **Adaptive visual evidence** - generate cleaner semantic overlays, distinct
  handle-group candidates, dense-view tile crops, deduplicated image-trace
  observations across overlapping tiles, and explicit pixel/world mapping.
- **Versioned source contracts** - snapshot, overlay, tile, and
  `VisualSourceRef/v1` metadata make coordinate lineage inspectable by strict
  consumers.
- **Calibrated review and evaluation** - reconcile VLM findings with grounding
  candidates and report coverage, ambiguity, abstention, and handle-quality
  metrics.
- **Stronger scans** - visual geometry is captured by default, with OCS-to-WCS
  normalization and improved hole-pattern semantics.
- **New documentation** - the English and Chinese READMEs are now concise,
  workflow-oriented entry pages with real AutoCAD examples.

## Compatibility notes

- No MCP tools were removed; new input fields are optional.
- The default drawing-review prompt is now `vlm_review_drawing/v3`.
- Visual contracts advance to `cad-view-snapshot/v3`,
  `cad-overlay-items/v2`, and `cad-view-tiles/v2`.
- Grounded paths/polygons identify themselves with
  `grounding_geometry_version=path-polygon/v1`.
- Public `scan_all_entities` now defaults to
  `capture_visual_geometry=true`; set it to `false` for a metadata-only scan.
- Coordinates measured from a tile or auto-downscaled inline image must echo
  that image's `source_ref_template` so the server can rebase them safely.
- Consumers that validate schemas strictly should update before ingesting new
  snapshots. Rescan drawings and regenerate old snapshots/overlays instead of
  mixing contracts.
- Python 3.11+, Windows, AutoCAD, ImageDrawingSpec v1, and CAD-IR v2 requirements
  are unchanged.

## Validation

- 368 non-AutoCAD tests passed.
- 471 subtests passed.
- 16 focused regression test modules cover topology, path/polygon grounding,
  overlay contracts, tracing snapshots, and evaluation behavior.

# v1.6.0 - 拓扑感知 CAD 视觉定位

v1.6.0 让视觉发现更可靠地回到精确 AutoCAD 几何：新增图纸级拓扑、真实路径/
多边形定位、更加明确的快照契约，以及校准后的审阅和评估闭环，同时保留原有的
句柄优先安全模型。

## 主要变化

- **图纸级边界拓扑**：可跨直线、圆弧、样条和多个实体组装闭合轮廓，不再只把
  每个实体当作独立包围框。
- **受支持交点与闭环遍历**：在直线-直线和受支持的直线-曲线交点拆分边界，
  遍历 half-edge 候选；遇到不支持或存在歧义的情况时安全拒绝。
- **路径和多边形定位**：为 VLM 发现返回贴合几何的区域、多句柄候选、歧义信号
  和语义形状证据。
- **自适应视觉证据**：更干净的语义覆盖层、独立句柄组候选、密集视图 tile、
  重叠 tile 的 image-trace 观测去重，以及明确的像素/世界坐标映射。
- **版本化来源契约**：快照、覆盖层、tile 和 `VisualSourceRef/v1` 元数据让
  坐标来源可审计。
- **校准审阅与评估**：把 VLM 发现与定位候选对齐，并报告覆盖率、歧义、放弃率
  和句柄质量指标。
- **更强扫描**：默认采集视觉几何，加入 OCS 到 WCS 规范化，并改进孔阵列语义。
- **全新首页文档**：中英文 README 统一为工作流导向入口，并加入真实 AutoCAD
  图例。

## 兼容性说明

- 没有删除 MCP 工具；新增输入字段均为可选。
- 默认图纸审阅提示词升级为 `vlm_review_drawing/v3`。
- 视觉契约升级为 `cad-view-snapshot/v3`、
  `cad-overlay-items/v2` 和 `cad-view-tiles/v2`。
- 路径/多边形定位通过 `grounding_geometry_version=path-polygon/v1` 标识。
- 公共 `scan_all_entities` 现在默认
  `capture_visual_geometry=true`；只需要元数据扫描时可显式设为 `false`。
- 从 tile 或自动缩放后的内联图测量坐标时，必须回传该图像的
  `source_ref_template`，以便服务安全地换算坐标。
- 严格校验 schema 的消费者应先升级，再读取新快照；旧快照和覆盖层建议重新
  扫描后重新生成，不要混用不同契约。
- Python 3.11+、Windows、AutoCAD、ImageDrawingSpec v1 和 CAD-IR v2 要求不变。

- 16 个重点回归测试模块覆盖拓扑、路径/多边形定位、覆盖层契约、trace 快照和评估。
