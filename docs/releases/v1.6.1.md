# v1.6.1 - MCP SDK compatibility hotfix

MCP Python SDK 2.0 removed the `mcp.server.fastmcp` compatibility path that
best-cad-mcp currently uses. Because v1.6.0 specified only a lower dependency
bound, fresh installs resolved MCP 2.0 and failed during server import and
Release CI.

This hotfix constrains the supported SDK range to
`mcp[cli]>=1.19.0,<2.0.0`. CAD tools, visual grounding, schemas, and DWG behavior
are unchanged. Native MCP 2.0 migration will be handled separately.

Upgrade with:

```powershell
python -m pip install --upgrade "best-cad-mcp==1.6.1"
```

## Validation

- Python 3.11.15 passed the full non-COM suite at both dependency boundaries:
  MCP 1.19.0 and the latest compatible MCP 1.29.0 (`332 passed`, `20 skipped`,
  `471 subtests passed`).
- Python 3.13.7 passed the same suite (`368 passed`, `471 subtests passed`).
- The wheel and source distribution passed Twine checks. A clean wheel install
  resolved MCP 1.29.0, passed `pip check`, imported the server, and passed
  `cad-mcp-doctor --json`.

https://github.com/LokmenoWer/best-cad-mcp/compare/v1.6.0...v1.6.1

# v1.6.1 - MCP SDK 兼容性热修

MCP Python SDK 2.0 移除了 best-cad-mcp 当前使用的
`mcp.server.fastmcp` 兼容路径。由于 v1.6.0 的依赖只设置了下限，全新安装
会解析到 MCP 2.0，导致服务导入和 Release CI 失败。

本热修将支持范围明确为 `mcp[cli]>=1.19.0,<2.0.0`。CAD 工具、视觉定位、
schema 与 DWG 行为均无变化。MCP 2.0 原生迁移将单独处理。

升级命令：

```powershell
python -m pip install --upgrade "best-cad-mcp==1.6.1"
```

  最新兼容版 MCP 1.29.0（`332 passed`、`20 skipped`、`471 subtests passed`）。

  `pip check`、服务导入和 `cad-mcp-doctor --json` 均通过。
